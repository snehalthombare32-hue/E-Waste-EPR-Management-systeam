💡 How is EPR Target calculated?

Standard Operating Procedure per E-Waste (Management) Rules, 2022

1

Select Financial Year

Identify the applicable financial year to determine the required target percentage mandated by the government rules.

2

Find EPR Percentage

Apply the statutory EPR rate:

  • 2023–24 → 60%
  • 2024–25 → 60%
  • 2025–26 → 70%
  • 2026–27 → 70%
  • 2027–28 onward → 80%
3

Compute Target (MT)

Multiply annual e-waste handled by the target percentage:

EPR Target = Annual E-Waste × Target % / 100
4

Compare Recycled vs Target

Evaluate actual recycling achievements against the statutory target:

Difference = Actual Recycled − EPR Target
5

Determine Compliance

If Actual Recycled ≥ EPR Target, mark as COMPLIANT. Otherwise, mark as NON-COMPLIANT.

6

Lookup Registration Fee

Find the one-time registration fee slab based on EPR Target quantity:

  • < 50 MT → ₹2,500
  • 50 to < 100 MT → ₹7,500
  • 100 to < 1,000 MT → ₹1,50,000
  • 1,000 to < 5,000 MT → ₹10,00,000
  • ≥ 5,000 MT → ₹15,00,000
